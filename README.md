```
        ESC   ·    ·     ·     ·    ·      ·   LCLK   ↑   RCLK  SCR↑   ·
        CTRL  ·    ·   SLOW  FAST   ·      ·    ←     ↓    →    SCR↓   ·
        SHIFT ·    ·     ·     ·    ·      ·    ·     ·    ·     ·     ·
```

MC (Minecraft) mode: hold L1+L2, tap G. Left half: WASD/Q/E/F/Shift/Ctrl as usual, G=Tab, Z–B=hotbar 1–5, Space holdable; hold GUI thumb for F1/F2/F3/F5/F11, /, L, hotbar 6–0. Same combo turns it off.

Flash: Actions → latest run → download `firmware` → double-tap reset on a half → copy its `.uf2` to the NICENANO drive.
